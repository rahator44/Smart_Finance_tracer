System Capabilities

Built for Performance, Security & Modularity

Engineered across four distinct architectural pillars, ensuring enterprise reliability and personal usability.

🏢

Corporate Office Finance

B2B client invoices, vendor payroll, operational burn rate, and liquid runway forecasting. Switch modes dynamically via MVVM state router.

Lead: Rahat (@rahator44)
⚡

Pocket Backend & Admin Portal

SQLite database engine with Entity Framework Core, TransactionService CRUD, site treasury oversight, and corporate license audit lifecycle.

Lead: Farabi (@mahdiazfar27)
🛡️

Security & Notifications

PBKDF2 cryptographic password hashing with unique salt, remember-me session caching, and non-blocking floating animated toast banners.

Lead: Rupom (@rupamimamhasan-86)
📊

Visual Reports & Personal Tracking

Dynamic budget health scores, visual cash flow charts, smart category prediction, and automated expense warning thresholds.

Lead: Raven (@raven-0-2)
